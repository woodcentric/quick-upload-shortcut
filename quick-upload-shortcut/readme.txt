Adds a convenient shortcut to the WordPress admin menu for uploading plugin ZIP files.

== Description ==

Quick Upload Shortcut adds an Upload Plugin submenu under Plugins in the WordPress dashboard.

It opens the native WordPress ZIP upload form directly, saving clicks when installing plugins.

WordPress continues to handle installation, permissions, and validation.

== Installation ==

1. Go to Plugins > Add Plugin > Upload Plugin.
2. Select quick-upload-shortcut.zip and click Install Now.
3. Activate Quick Upload Shortcut.
4. Go to Plugins > Upload Plugin to access the shortcut.

== Frequently Asked Questions ==

= Does this replace the WordPress plugin installer? =

No. It opens the existing WordPress plugin upload interface.

= Does this plugin require configuration? =

No. Simply activate it to add the shortcut.
