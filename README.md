# Quick Upload Shortcut

A free WordPress plugin developed by Plugin Place.

## Features
- Adds an Upload Plugin shortcut under the WordPress Plugins menu.
- Opens the built-in WordPress ZIP upload form directly.
- Requires no additional configuration.

## Installation
1. Download the latest plugin ZIP from GitHub Releases.
2. In WordPress, go to Plugins > Add Plugin > Upload Plugin.
3. Upload the ZIP and activate the plugin.
